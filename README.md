## 📌 Project Overview
GlobalTrade Logistics Corporation Platform is a Java EE / Jakarta EE enterprise supply chain management system featuring:
- **EJB Module (`globaltrade-ejb`)**: Stateless, Stateful, & Singleton Session Beans, Timers, Interceptors, CMT/BMT Transactions, JPA Entities, & Repositories.
- **Web Module (`globaltrade-web`)**: RESTful Services (JAX-RS), Multi-Portal User Interfaces, and JWT-based authentication.
- **EAR Module (`globaltrade-ear`)**: Enterprise Archive packaging for WildFly/GlassFish deployment.
